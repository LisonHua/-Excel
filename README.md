# Excel 抽奖系统

这是一个基于 Flask 的网页抽奖工具。你只需要上传一个包含人员姓名的 Excel 文件，选择姓名列和中奖人数，点击“开始抽奖”，系统就会随机抽取中奖名单并弹窗展示。

## 功能特点

- 支持上传 `.xlsx` / `.xls` 文件
- 自动读取 Excel 表头并选择姓名列
- 可自定义一次抽奖人数
- 随机抽取且不重复
- 抽奖结果弹窗展示

## 本地运行

1. 安装依赖：

```bash
pip install -r requirements.txt
```

2. 启动服务：

```bash
python web_excel_merger.py
```

3. 浏览器打开：

```text
http://localhost:5000
```

## 使用说明

1. 上传包含人员姓名的 Excel 文件。
2. 在“选择姓名列”中指定对应的姓名字段。
3. 输入中奖人数。
4. 点击“开始抽奖”。
5. 系统会弹窗显示中奖名单。

## 注意事项

- 中奖人数不能超过姓名列中的有效人数。
- 空白单元格会自动忽略。
- 每次抽奖都是随机结果，中奖名单不会重复。
